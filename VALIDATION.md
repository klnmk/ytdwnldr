## Что изменено

- Вертикальный QSplitter с заметной ручкой; сворачивание очереди до заголовка, восстановление высоты и прокрутки, сохранение высоты / состояния в portable-настройках. Активные загрузки продолжают получать прогресс при свёрнутой панели.
- Удаление записи в любом состоянии: ×, контекстное меню, Delete. Для работающей задачи сначала отменяется дерево процессов; поздние события не возвращают удалённую запись. «Повторить» остаётся отдельным действием.
- «Очистить очередь» удаляет все записи; при активных загрузках требуется подтверждение. Файлы на диске не удаляются. history.json содержит сохранённую очередь, отдельного архива истории нет; удаление обновляет и её.
- Вся строка плейлиста переключает отметку: название, длительность, пустое место и checkbox. Checkbox переключается один раз. Добавлены Space и фон отмеченных строк; недоступные записи остаются недоступными.
- Компактная собственная полоса окна с кнопками, двойным щелчком, системным перемещением / изменением размера Qt и зонами краёв / углов. Закрытие использует прежнюю остановку рабочих процессов. Максимизация проверена в пределах рабочей области Windows.
- Размер текущего потока из downloaded_bytes / total_bytes / total_bytes_estimate, знак ~ для оценки, корректное неизвестное общее значение. Раздельные видео / аудио не складываются. После обработки размер результата читается с диска. Высота строки очереди выросла с 68 до 76 px.

Алгоритмы выбора форматов и конвертации не переписаны. Изменения engine ограничены передачей размера в событиях. Основная графика, цвета, шрифты и архитектура сохранены.

## Проверка упакованного EXE

`scripts/verify_release.py` копирует всю сборку в `artifacts/relocation-test/Съём Portable/`, убирает Python / FFmpeg из PATH, удаляет PYTHONHOME / PYTHONPATH / настройки поиска Qt. GUI и worker метаданных завершаются с кодом 0; миниатюра записана в корректный кириллический путь.

В EXE выполнено **24 проверки взаимодействий**: по шесть на offscreen, native Windows 100%, 125% и 150%. Во всех четырёх запусках exit code 0. Проверены отсутствие native title bar, minimize / maximize / restore, границы work area, title / duration / checkbox, resize / collapse / scroll / persisted-height, failed / pending removal и Clear All с сохранением файла.

Native work area: 1920 × 1032 при 100%, 1536 × 826 при 125%, 1280 × 688 при 150%. Масштаб задан через QT_SCALE_FACTOR; системная настройка DPI не переключалась. Native проверки запускались в прозрачном тестовом окне без управления пользовательским рабочим столом.

Диагностический `--verify-ui` создаёт только изолированные fixtures в `data/ui-verification/`. В обычном запуске их нет. Изображения просмотрены, наложений панелей не обнаружено.

## Реальные загрузки и удаление

Упакованный worker скачал [Big Buck Bunny](https://www.youtube.com/watch?v=YE7VzlLtp-4), Blender. Выходы проверены через ffprobe, final_size совпал с размером каждого файла:

| Формат | Результат | Размер файла |
|---|---|---:|
| MP4 1080p | H.264 / AAC, 1920 × 1080, 24/1 fps, 596.52 с | 233 174 867 байт |
| MP3 320 | 320000 бит/с, title / artist, JPEG-обложка | 23 952 277 байт |
| M4A | AAC 128007 бит/с, title / artist, JPEG-обложка | 9 715 268 байт |

MP4 в первом запуске получен за 162.84 с, MP3 — за 16.56 с. Видео и звук скачивались раздельно: video-байты выросли от 1024 до 72 320 758, audio — от 261 120 до 9 655 276. Счётчики увеличивались независимо и не выдавались за итоговый размер MP4. Первые 3 секунды нового MP4 декодированы FFmpeg, exit code 0.

**Первый M4A-запуск завершился ошибкой доступности формата источника. Один повтор успешно скачал M4A за 7.43 с.** MP4 / MP3 в этом повторе распознаны по квитанциям и пропущены. Первоначальные результаты сохранены отдельно; ошибка не скрыта. Реальных потоков с неизвестным / оценочным размером в этом запуске не было, эти случаи проверены автотестами.

`verify_live_queue.py`: реальный MP3 192 [Me at the zoo](https://www.youtube.com/watch?v=jNQXAC9IVRw) через GUI / QProcess — 7.33 с, итоговый размер **479 507 байт**, показанное значение совпало с диском. Максимальный разрыв между 20-мс Qt-событиями — **0.033 с**.

`verify_queue_removal.py`: настоящий ожидающий job удалён до запуска, работающий video-job удалён после поступления 1024 байт, затем проверена подтверждённая очистка новой очереди с активными jobs. После завершения не осталось трёх наблюдавшихся workers и шести дочерних процессов. persisted-очередь пуста; проверка выполнена в изолированном каталоге, настройки пользователя не менялись.

## Ручная проверка и ограничения

Не выполнены и не объявляются пройденными:

- Windows 10 на отдельном компьютере; второй компьютер без Python / FFmpeg.
- Реальное перетаскивание указателем, resize всех краёв / углов, dragging из maximized, Snap, переключение мониторов и восстановление кликом по taskbar.
- Alt+F4 на настоящем Windows desktop; кнопка закрытия и общий shutdown проверены автоматически.
- Системные DPI-настройки / разные физические дисплеи. Проверено Qt-масштабирование на Windows platform.
- Полный просмотр файлов в нескольких внешних медиаплеерах.

EXE не подписан. Нет тёмной темы, cookies / входа в аккаунт, DRM, закрытых видео и активных эфиров. YouTube может ограничивать потоки по IP / региону; M4A потребовал повтор в этой проверке. Лицензии и условия публичного распространения сторонних бинарников остаются в `THIRD_PARTY.md`.
