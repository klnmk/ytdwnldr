# Проверка СЪЁМ 1.0.0

Дата: **10 октября 2026 года**. Среда: Windows 11 x64, build 26200; Python 3.12.1 для разработки. Готовый EXE содержит свой Python runtime. Проверены PySide6-Essentials 6.12.0, yt-dlp 2026.8.19, FFmpeg 9.0.2, Deno 2.9.7 и PyInstaller 6.22.3. Точные версии и SHA-256 инструментов находятся в lock-файлах.

## Автоматические проверки

Последняя сборка: **63 passed in 4.81s**, ошибок нет. Команда: `.venv\Scripts\python.exe -m pytest -q`; она также выполняется в `build.bat` перед упаковкой.

Проверены URL / Shorts / плейлисты, нормализация и дубли, точный выбор разрешения без скрытого снижения, настройки yt-dlp, безопасные Unicode-имена, сохранение и перенос настроек / истории, повреждённый JSON, ошибки записи, коллизии, квитанции существующих файлов, очереди, параллельность, отмена и повтор, отсутствие ложного завершения, недоступное качество и большой список.

Интеграционные тесты запускают настоящие FFmpeg / ffprobe на локально созданных видео и звуковом сигнале:

- MP3: 128 / 192 / 256 / 320 кбит/с, фактический кодек и битрейт.
- MP4: быстрое сохранение VP9 / Opus; совместимый H.264 / AAC, 256 × 144, 24 fps без изменения размера / частоты кадров.
- M4A: AAC без перекодирования, теги; WAV: PCM.
- Встраивание обложки MP3 / M4A; имитация ошибки записи обложки подтверждает сохранность исходного готового аудио.
- Полная локальная цепочка скачивания с замоканным сетевым источником, атомарный результат, пропуск по квитанции.
- Уничтожение дерева дочерних процессов через Windows Job Object, отмена при запуске, кириллица в JSON-протоколе оконного EXE.
- При размере окна 880 × 752 / 650 / 520 панели не перекрываются, прокрутка открывает нижние действия.

Локальные сигналы и замоканный источник проверяют обработку медиа, но сами по себе не доказывают работу YouTube.

## Запуск EXE и измерения

Сборка `onedir` скопирована в `artifacts/relocation-test/Съём Portable/`. Для запуска PATH содержал только Windows System32; PYTHONHOME, PYTHONPATH и настройки поиска Qt удалены. Пустой GUI и сетевой worker метаданных успешно завершились с кодом 0. Worker загрузил миниатюру в корректный кириллический путь, stderr пустой.

| Измерение | Результат / метод |
|---|---|
| Запуск упакованного GUI до отрисованного окна | **0.759 с**, `--verify-startup`, Qt offscreen, включая 100 мс таймер готовности |
| Idle RAM | **73.2 MiB RSS** процесса GUI после готовности |
| Idle CPU | **0.0%** за один двухсекундный интервал |
| Сетевые соединения при пустом запуске | **0** соединений inet в момент наблюдения |
| Portable-папка | **около 383 MiB**, включая Python / Qt, FFmpeg / ffprobe, Deno, лицензии и source.zip |
| Source GUI | 0.146 с создание / отрисовка виджетов после импорта модулей |
| Большой список | **10000 синтетических записей**, установка модели и обработка Qt paint: **0.010 с** |
| Реальная загрузка через GUI | Наибольший разрыв между событиями 20-мс Qt-таймера: **0.031 с** |

Это результаты одного компьютера, не гарантированные характеристики. ОС-кеш перед запуском не очищался; строгий cold boot не измерялся. Измерение RAM относится к пустому GUI, не к сумме GUI / yt-dlp / Deno / FFmpeg при загрузке. Краткий замер CPU и соединений не является длительным мониторингом. Размер и SHA-256 готового ZIP записываются в `artifacts/package-metrics.json` и `dist/ytdwnldr-portable.zip.sha256` после упаковки.

Во время упаковки исключены ненужные Qt-модули и OpenGL fallback. Исключены также ICU DLL стороннего host-инструмента, несовместимые с Qt и затенявшие системную ICU Windows; проверка запуска выполнялась после этого исправления.

## Оставшиеся ручные проверки и ограничения

- Отдельного физического Windows 10 / 11 компьютера без установленного Python в этой сессии нет. Перенос и изоляция PATH проверены на этом Windows 11; это не равнозначно проверке на втором компьютере.
- Ручное воспроизведение целых файлов в нескольких внешних медиаплеерах не выполнялось. Выполнены ffprobe и трёхсекундное декодирование реального MP4.
- Нет тёмной темы, авторизации через cookies / аккаунт, DRM, закрытых видео и активных эфиров. Публичный YouTube может менять доступность потоков и ограничивать запросы по IP / региону; ошибки источника остаются возможными.
- EXE не подписан. Условия дальнейшего публичного распространения сторонних бинарников и corresponding source описаны в `THIRD_PARTY.md`.

Сценарии для оставшейся ручной проверки и команды разработки находятся в `README.md`.
